# دليل تشغيل برنامج تعريب الألعاب على نظام ويندوز (Windows Guide)

استوديو تعريب ألعاب متكامل مع دعم ملفات Excel (`.xlsx`, `.xls`, `.csv`) وملفات النصوص `TXT` و `JSON`.

---

## 🚀 الطريقة الأسرع للتشغيل (بنقرة واحدة):

1. تأكد من تثبيت بيئة **[Node.js](https://nodejs.org)** (نسخة LTS المجانية).
2. انقر نقراً مزدوجاً على الملف:
   👉 **`start-windows.bat`**
3. سيقوم الملف تلقائياً بـ:
   - فحص وجود Node.js.
   - تثبيت كافة الحزم المطلوبة (`npm install`).
   - بناء ملفات الواجهة والترجمة.
   - تشغيل الخادم وفتح المتصفح تلقائياً على الرابط: `http://localhost:3000`.

---

## 💻 التشغيل اليدوي عبر موجه الأوامر (CMD أو PowerShell):

إذا أردت تشغيله يدوياً:
```bash
# 1. تثبيت المكتبات
npm install

# 2. تشغيل وضع التطوير السريع
npm run dev
```
ثم افتح متصفح الإنترنت على: `http://localhost:3000`

---

## 🔑 مفتاح ترجمة الذكاء الاصطناعي (اختياري للترجمة السحابية):
- إذا أردت استخدام ترجمة Gemini التلقائية، أنشئ ملفاً باسم `.env` في نفس المجلد وضع فيه:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
- يمكنك أيضاً ترجمة وتحرير النصوص يدوياً بدون الحاجة إلى أي مفتاح.
